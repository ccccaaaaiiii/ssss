# ssss

Extensao do Stremio.

## Objetivo
Criar a extensao ssss para Stremio que pesquisa no Twitter, encontra links de video no Google Drive e reproduz esses links no addon.

## Escopo inicial
1. pesquisar publicacoes no Twitter e localizar fontes uteis
2. obter links de video do Google Drive a partir dessas fontes
3. reproduzir esses links dentro do addon do Stremio

2. addon.js
